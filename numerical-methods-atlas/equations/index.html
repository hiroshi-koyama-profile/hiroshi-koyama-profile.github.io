Poisson・Laplace方程式

LWR交通流モデル

∂ₜρ + ∂ₓ[ρ(1 − ρ)] = 0

無次元化した代表流束。渋滞の上流伝播と希薄化を調べる。

圧縮性Euler方程式

∂ₜU + ∂ₓF(U) = 0
U = (ρ, ρu, E)ᵀ
F = (ρu, ρu² + p, u(E + p))ᵀ

1次元の保存形。状態方程式と初期・境界条件は各テストの定義を参照する。

浅水方程式

∂ₜh + ∂ₓ(hu) = 0

平坦な底面・1次元・摩擦なしの代表形。水深hと重力加速度g。ダム崩壊の参照解へ。
