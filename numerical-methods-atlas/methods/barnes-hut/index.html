重力と長距離相互作用

Barnes–Hut八分木

教育用例・関連コードあり

粒子を八分木にまとめ、遠方セルの質量モーメントで孤立重力を近似します。直接和と同じ軟化核で力誤差を比べられます。

手法の見取り図コード・入力・検証解説章の目次

解説と位置付け

解説章を読む

この例の前提

  • 3次元の孤立した粒子系・正の質量
  • Plummer軟化を用いたNewton重力
  • 標的粒子を含むノードは必ず開き、自己相互作用を除外

境界条件: 孤立境界。周期境界ではありません。

単位系: 無次元の例でG=1。長さ・質量・軟化長の規約を揃えて比較します。

Particle fields & gravity

Barnes–Hut octree

Educational example / related code

Approximate isolated particle gravity with an octree and cell moments; compare force error with the identical softened direct sum.

Method mapCode, inputs and checksReading chapters

Read the formulation

Read the chapter

Assumptions for this example

  • 3D isolated particles; positive masses
  • Plummer-softened Newton kernel
  • A node containing the target is always opened; self-interaction is excluded

Boundaries: isolated; not periodic

Units: Dimensionless examples with G=1; retain the chosen length, mass and softening conventions.

Use explicit positions and masses for 192 particles. Compute tree and direct-sum forces, then export error/check records as JSON and particle forces as CSV.

Scope and remaining work

Static force comparisons only. Target-wise approximation need not conserve pair momentum exactly; interaction counts are not timings. This is not an FMM or TreePM implementation.
