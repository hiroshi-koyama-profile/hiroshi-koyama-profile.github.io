取得から引用までの共通手順

  1. 条件を読む

    例ごとの前提、単位、境界、モデルの限界を確認します。

  2. ZIPと入力を取得する

    対応するZIPを新しいフォルダへ展開します。入力リンクから固定条件を確認します。

  3. 依存関係を準備する

    Python環境を用意し、その配布版のフォルダで例ごとのインストール手順を実行します。

  4. 計算して出力を保存する

    実行場所とコマンドを確認して実行します。公開された参照出力は上書きせず、別の出力先を使います。

  5. 値と失敗理由を確かめる

    表のJSON内の場所と許容誤差を確認します。テスト通過、出力生成、物理的な妥当性は別に判断します。

  6. 版と出典を残す

    入力の変更、コード版、ハッシュ、参照した手法論文、ページURLと確認日を計算記録に残します。

式・図・誤差の解説 · 対応するコードZIP

前提
非相対論・無限質量の点核。核電荷Z=1,2。縮約動径軌道を一様格子の2次中心差分で離散化。
単位
原子単位系：エネルギーhartree、距離bohr。
境界・モデルの範囲
孤立系、u(0)=u(r_max)=0。主計算r_max=60 bohr。H 1sの領域打切り依存は別に検査。

A common path from download to citation

  1. Read the conditions

    Check the assumptions, units, boundaries and model limits for your case.

  2. Download the ZIP and input

    Extract the corresponding ZIP into a new directory and inspect the fixed input at its link.

  3. Prepare the dependencies

    Prepare a Python environment and run the installation command from that extracted edition directory.

  4. Run and save the output

    Use the stated working directory and command. Write to a separate output directory so packaged reference results remain intact.

  5. Check values and failure reasons

    Compare the indicated JSON fields with the reference values and tolerances. Passing tests, producing files and physical adequacy are distinct checks.

  6. Keep the version and sources

    Retain input changes, code version and hashes, original method papers, page URL and access date in your computation record.
